战略机会洞察 · 使用指南

演变自华为"五看"框架 · 融合波士顿矩阵双维定位思想 · 适用于任何行业

战略机会洞察是面向任何行业的战略机会调研工具，演变自华为"五看"战略洞察框架，融合波士顿矩阵双维定位思想，帮助团队从市场全景出发，系统识别、评估和排序业务机会，输出决策级洞察报告。

🎯 给谁用

需要做方向选择的团队或组织——创业公司选赛道、企业探索新业务线、投资人评估赛道机会。

💡 解决什么问题

凭直觉选方向 / 被现有业务框住 / 知道市场大但不确定能不能做 / 机会太多无法系统比较。

方法论体系

五看递进

源自华为五看

看趋势→看客户→看对手→看自己→看机会，从市场全景逐步收窄到机会聚焦

双维矩阵

融合波士顿矩阵

市场吸引力 × 组织适配度，独立计算、独立呈现，四象限定位

结构化深描

8维度机会画像

每个候选机会从8个维度做全景深描，确保评估有据可依

落地验证

四维硬筛 · 可行性分析

明星区机会过四道筛子：短期收入 / 执行带宽 / 资源可承受 / 渠道可触达

核心流程
五阶段递进式调研——第一看行业趋势（7维）→ 第二看客户市场（5维）→ 第三看竞争格局（6维）→ 第四看自身能力（4维）→ 第五看机会评估（5个Phase：扫描30-50候选→8维深描15-25个→双维矩阵评分→落地验证→汇总排序）。前四看强制纯客观，所有数据标注来源链接。
差异化三点
  • 市场优先——强制前四看纯客观，不被自身业务框住
  • 双维解耦——市场吸引力不引入组织信息，组织适配度不参考市场规模，独立计算独立呈现
  • 落地硬验证——明星区机会必须过四道筛子，拒绝"看着好但做不了"

数据获取：联网搜索 + 网页阅读，不依赖任何外部付费API。

你只需要：回答3轮15题（约30min）→ 工具自动联网调研→扫描→深描→评分→矩阵→验证→输出11份交付物。

Phase 0 · 调研方案生成
💬 用户Q&A
通过3轮结构化问答收集组织信息，确定调研行业方向，生成调研方案文档
轮次 问题 喂给哪个环节
第一轮
组织构成		1. 团队/组织有多少人？组织适配度·执行带宽
2. 成员各自角色是什么？组织适配度·战略协同
3. 核心技能有哪些？组织适配度·技术匹配
4. 每人可投入时间？落地验证·执行带宽
5. 地理分布？落地验证·渠道可触达
6. 谁是实际技术主力？组织适配度·技术匹配（关键）
第二轮
产品与技术		7. 现有产品处于什么阶段？组织适配度·战略协同
8. 当前用户数和营收？落地验证·短期收入
9. 技术栈是什么？组织适配度·技术匹配
10. 有哪些可复用技术资产？组织适配度·资源匹配
第三轮
资源与渠道		11. 资金状况如何？落地验证·资源可承受
12. 有哪些客户渠道？落地验证·渠道可触达
13. 协作方式？组织适配度·执行带宽
14. 想调研什么行业/方向？确定调研方向（关键）
15. 关注哪个市场层级？市场层级定位
📤 输出：调研方案文档（含五看框架说明、各看维度、时间规划、信息来源标准、调研行业方向）
第一看 · 看趋势
📐 PEST 🔍 联网搜索 📄 网页阅读 🧠 LLM知识
7个维度全面扫描目标行业趋势，纯客观描述
  • 政策与监管环境 — 监管框架 / 行业准入 / 合规要求
  • 经济与市场环境 — 宏观经济 / 消费力 / 市场周期
  • 社会与消费趋势 — 用户行为变迁 / 人口结构 / 消费习惯
  • 关键技术演进 — 核心技术发展 / 成本曲线 / 成熟度
  • 市场规模与增速 — TAM / SAM / SOM
  • 资本流向 — 投融资热点 / 估值水平 / 退出路径
  • 产业链价值迁移 — 价值在向哪里转移
⚠️ 纯客观：不出现"建议""应该""值得""推荐"等判断性词汇 · 必须覆盖中小视角 · 所有数据标注来源链接
📤 输出：趋势简报（7章，每章2-5小节，Markdown格式）
第二看 · 看客户市场
📐 市场细分 🔍 联网搜索 📄 网页阅读 🧠 LLM知识
5个维度分析客户分层、痛点、付费意愿和决策链
  • 客户分层画像 — 大企业 / 中小企业 / 个人用户 / 开发者
  • 各层级痛点与未满足需求
  • 付费意愿与预算分析
  • 客户获取渠道与成本
  • 客户决策链分析
📤 输出：客户市场简报（5章，Markdown格式，标注来源）
第三看 · 看对手
📐 波特五力 🔍 联网搜索 📄 网页阅读 🧠 LLM知识
6个维度分析竞争格局，重点覆盖同阶段竞品和竞争空白
  • 头部玩家格局 — 大厂布局 / 行业龙头
  • 同阶段竞品 — 同规模/同阶段参与者（必须覆盖）
  • 替代方案与新进入者威胁
  • 竞品定价模式对比
  • 竞品技术路线对比
  • 竞争空白点识别
📤 输出：竞争格局简报（6章，Markdown格式，标注来源）
第四看 · 看自己
📐 VRIO 💬 用户Q&A
4个维度盘点组织能力和资源，基于Q&A收集，不联网
  • 组织能力矩阵 — 技术/产品/销售/渠道，每项标注强/中/弱
  • 资源盘点 — 资金/人脉/数据/渠道/时间
  • 现有产品与技术资产
  • 能力-机会初步对照 — 仅客观罗列，不做判断
📤 输出：内部能力盘点（4章，Markdown格式）
第五看 · 看机会（市场驱动五步法）
综合前四看
将前四看的洞察转化为可评估、可排序的机会清单。5个Phase逐步收窄。
P1 机会扫描
从前四看报告中系统扫描机会候选
  • 从市场趋势 → 识别增量市场
  • 从客户痛点 → 识别未满足需求
  • 从竞争空白 → 识别差异化机会
  • 从技术趋势 → 识别新兴可能
🧠 LLM分析（基于前四看报告）
📤 输出：30-50个机会候选（编号+名称+一句话描述+来源看）
P2 初筛合并 + 8维深描
先合并重叠、淘汰弱信号 → 保留15-25个 → 每个做8维深度画像
  • 初筛：合并重叠机会 + 淘汰弱信号 → 15-25个
  • 8维深描：① 机会定义 ② 市场规模(TAM/SAM/SOM) ③ 客户画像 ④ 竞争格局 ⑤ 技术可行性 ⑥ 商业模式 ⑦ 时机窗口 ⑧ 风险因素
🔍 联网搜索 📄 网页阅读 验证市场规模/竞品/技术成熟度
📤 输出：15-25个机会深描文档（每个800-1500字，附来源链接）
P3 双维矩阵评估
每个机会打两个独立分数，互不干扰
📊 市场吸引力（100分）
市场规模30%
盈利潜力25%
竞争空白度20%
时机窗口15%
风险可控10%
只看市场，不引入任何组织信息
👥 组织适配度（100分）
技术匹配30%
资源匹配25%
渠道匹配25%
战略协同20%
只看组织，不参考市场规模
📐 波士顿矩阵 🧠 LLM分析计算（基于P2深描+第四看组织信息）
⚠️ 两个分数独立计算、独立呈现，不合并为单一总分 · 每个维度需给出50-100字评分依据
📤 输出：25个机会 × 2个独立分数 + 逐维度评分依据
