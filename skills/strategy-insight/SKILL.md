# 战略机会洞察：组合工作流

按用户想得到的结果选择一个模式：

| 用户的说法 | 模式 | 停在哪里 |
| --- | --- | --- |
| “把行业、客户、对手和我们自己看清楚” | 四看调研 | 四份调研简报 |
| “帮我找有哪些业务方向” | 寻找机会 | 机会扫描、初筛和8维深描 |
| “比较我给出的几个方向” | 比较机会 | 双维评分、四象限和落地验证 |
| “从头到尾做战略机会调研” | 完整洞察 | 原版11份交付物 |

未说明模式时，先根据用户实际问题选择；仍有歧义时只问一个澄清问题。不要因为用户询问一个方向，就擅自扩展为完整调研。

## 共同起点：Phase 0

任何模式首次启动都先读 [3轮15问](references/intake.md)，按轮收集并记录全部15项。用户已经提供完整调研档案时，逐项核对是否仍适用，再复用；缺项只补缺项。15项齐备后确定行业、地域、市场层级、时间范围和调研对象，生成调研方案。不要在未完成Phase 0时进入正式调研。

## 执行依赖

1. **四看**：按 [四看说明](references/four-views.md) 调研趋势、客户、对手、自己。可用时依次使用 `strategy-trends`、`strategy-customers`、`strategy-competitors`、`strategy-capabilities` 四个技能；只安装本工作流技能时则按引用文件执行同样的四看。四份简报可分别制作；完整工作流使用全部四份。前三看需要联网搜索并阅读来源，第四看依据用户提供的组织资料。前四看保持事实与证据陈述，不写优先级或行动建议。
2. **寻找机会**：确认四份简报同属此次调研范围，按 [机会流程](references/opportunity-workflow.md) 执行扫描、合并初筛和8维深描。若此前产物齐备，直接复用；否则先补齐缺失的“看”。
3. **比较机会**：先核对四份简报，缺少的先补做。用户给出候选时，仅比较这些指定机会；没有候选时，先执行寻找机会。逐项补齐8维深描，再按 [评分标准](references/scoring_criteria.md) 计算市场吸引力和组织适配度、定位象限，并只对明星区做四项落地验证。指定机会比较须标明不是全市场机会扫描。
4. **完整洞察**：从Phase 0到第五看全部执行，按 [交付模板](references/templates.md) 交付原版11份成果。此处只做“五看”战略洞察，不代替团队完成“三定”。

每个阶段开始前检查已有产物的行业、地域、时间和来源；不一致或过期时说明并补查受影响部分。机会编号在扫描、深描、评分和报告中保持一致。保存文件时使用工作区中用户指定的位置；没有文件工具时在对话中给出可复制的Markdown结果。

## 证据与边界

- 前三看的事实、市场规模、定价、竞争信息与时效性判断要通过可用的搜索和网页阅读工具核实，关键结论附来源及日期；不依赖付费API。
- 将公开事实、计算估算、用户自述和分析推断区分开。资料不足时标出未知项，不编造精确市场规模或评分依据。
- 市场吸引力只使用市场证据，组织适配度只使用组织资料；两项独立评分、独立呈现，不加总。
- 四象限阈值沿用原版：市场吸引力≥60、组织适配度≥50为明星区。评分细则见引用文件。
- 使用 [离线战略矩阵HTML模板](assets/matrix.html)。有文件生成能力时填入评分数据并生成独立HTML；否则输出文本四象限表。
- 若平台没有联网能力，暂停需要外部核实的阶段并说明缺少的证据；不得把模型记忆写成已验证的调研事实。
