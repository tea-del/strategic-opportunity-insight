# 调研模板集

## Phase 0：组织Q&A模板

分3轮收集，共15个问题：

### 第1轮：组织构成（6题）
1. 团队/组织有多少人？ → 组织适配度·执行带宽
2. 成员各自角色是什么？ → 组织适配度·战略协同
3. 核心技能有哪些？ → 组织适配度·技术匹配
4. 每人每天能投入多少时间？是否有其他全职工作？ → 组织适配度·执行带宽
5. 团队成员的地理位置分布？ → 组织适配度·执行带宽
6. 谁是实际技术主力？ → 组织适配度·技术匹配（关键）

### 第2轮：产品与技术（4题）
7. 现有产品处于什么阶段？（概念/开发中/已上线/已搁置） → 组织适配度·战略协同
8. 各产品的用户数和营收数据？ → 组织适配度·战略协同
9. 技术栈是什么？ → 组织适配度·技术匹配
10. 有哪些可复用技术资产？ → 组织适配度·资源匹配

### 第3轮：资源与渠道（5题）
11. 资金状况如何？有融资计划吗？ → 落地验证·资源可承受
12. 有哪些客户资源或渠道？ → 落地验证·渠道可触达
13. 协作方式？（线上/线下/混合，多久开一次会） → 组织适配度·执行带宽
14. 本次调研关注什么行业/方向？ → 确定调研方向
15. 关注的市场层级？（头部/中小/独立开发者） → 市场层级定位

## 前四看报告结构模板

### 第一看：看趋势（靠接PEST分析，建议7章）
```
# 行业趋势简报
## 1. 宏观技术/行业趋势
## 2. 应用层/业务层趋势
## 3. 开发者/从业者生态趋势

## 5. 政策与合规趋势
## 6. 市场规模与增速
## 7. 产业链价值迁移
```

```
# 客户市场简报

## 3. 付费意愿与预算分析
```
