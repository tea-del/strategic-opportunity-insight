# 双维矩阵评估标准详解

## 设计理念

将机会评估拆分为两个完全独立的维度，各自从不同角度评估，避免单一分数掩盖关键信息。靠接波士顿矩阵/GE矩阵的双维定位思想。

- **市场吸引力**：回答"这个机会有多大？"——只看市场，不看组织
- **组织适配度**：回答"我们能不能做？"——只看组织，不看市场

两个分数独立计算、独立呈现，在战略矩阵中交叉定位。

---

## 市场吸引力（100分）

### 1. 市场规模（30分）

| 分数区间 | 标准 | 数据来源 |
|---------|------|---------|
| 25-30 | TAM > 100亿人民币 | 行业报告、上市公司财报、政府统计 |
| 18-24 | TAM 10-100亿 | 同上 |
| 10-17 | TAM 1-10亿 | 同上 |
| 0-9 | TAM < 1亿或无法估算 | — |

**注意：** 估算TAM时需说明假设（如"假设中国50万餐饮店中10%采用，年费2万"），不要直接引用无来源的数字。

### 2. 盈利潜力（25分）

| 分数区间 | 标准 |
|---------|------|
| 20-25 | 高客单价（年付>5万）+ 高复购率 + 高毛利（>70%） |
| 12-19 | 中等客单价 + 中等复购 或 高客单价低复购 |
| 5-11 | 低客单价但量大 或 中等客单价一次性 |
| 0-4 | 低客单价 + 低复购 + 低毛利 |

### 3. 竞争空白度（20分）

| 分数区间 | 标准 |
|---------|------|
| 16-20 | 无直接竞品，或竞品刚起步未验证模式 |
| 10-15 | 有竞品但较弱（产品不成熟/覆盖不足/刚上线） |
| 5-9 | 有成熟竞品但存在差异化空间 |
| 0-4 | 红海市场，多家成熟竞品，差异化空间极小 |

### 4. 时机窗口（15分）

| 分数区间 | 标准 |
|---------|------|
| 12-15 | 技术刚成熟 + 需求正在爆发 + 政策支持 |
| 7-11 | 技术成熟但需求尚未爆发，或需求爆发但技术尚不完善 |
| 3-6 | 技术远未成熟，或市场已接近饱和 |
| 0-2 | 时机已过或远未到来 |

### 5. 风险可控（10分）

| 分数区间 | 标准 |
|---------|------|
| 8-10 | 低风险（技术成熟、政策明确、无替代威胁） |
| 4-7 | 中风险（存在政策不确定性或技术快速迭代风险） |
| 0-3 | 高风险（政策可能禁止、技术可能被颠覆、合规门槛高） |

---

## 组织适配度（100分）

### 1. 技术匹配（30分）

| 分数区间 | 标准 |
|---------|------|
| 25-30 | 可直接复用组织现有技术栈，无需新学 |
| 15-24 | 核心技术复用，需补充部分新技能 |
| 5-14 | 需要较多新技术学习，但有技术基础 |
| 0-4 | 技术方向与组织能力完全不匹配 |

### 2. 资源匹配（25分）

| 分数区间 | 标准 |
|---------|------|
| 20-25 | 资金充足、人手够用、时间充裕 |
| 12-19 | 资源勉强够用，需精打细算 |
| 5-11 | 资源明显不足，需外部支持 |
| 0-4 | 资源严重不足，无法启动 |

### 3. 渠道匹配（25分）

| 分数区间 | 标准 |
|---------|------|
| 20-25 | 有现成客户渠道可直接触达目标客户 |
| 12-19 | 无直接渠道但可通过现有资源搭建 |
| 5-11 | 需要从零建立渠道，但路径清晰 |
| 0-4 | 无法触达目标客户，渠道建设困难 |

### 4. 战略协同（20分）

| 分数区间 | 标准 |
|---------|------|
| 16-20 | 与现有产品/业务强协同，可形成闭环 |
| 10-15 | 与现有业务弱相关，有一定协同空间 |
| 5-9 | 与现有业务无关但团队有兴趣 |
| 0-4 | 与现有业务和团队方向冲突 |

---

## 评分执行要点

1. **市场吸引力评分时完全不引入组织信息**：评分者不应知道组织的技术栈、资源、渠道
2. **组织适配度评分时完全不参考市场规模**：只看组织是否能做，不看市场是否值得做
3. **每个维度需给出具体分数和50-100字的评分依据**：不能只给分不解释
4. **评分依据需引用具体数据**：市场规模引用来源，技术匹配引用组织技术栈
5. **双维解耦**：两个分数独立计算、独立呈现，不合并为单一总分
6. **并行评分时可通过sessions_spawn分批执行**：每批5个机会，task中传入完整评分标准和对应机会的深描内容
