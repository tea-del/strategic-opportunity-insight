# 战略机会洞察

把“五看”拆成可单独使用的调研技能和可串联的机会洞察流程。

简体中文 · [English](README.md)

[完整使用指南（交互式）](https://tea-del.github.io/strategic-opportunity-insight/guide.html)

## 这是什么

战略机会洞察是面向任何行业的战略机会调研工具，演变自华为“五看”战略洞察框架，融合波士顿矩阵双维定位思想，帮助团队从市场全景出发，系统识别、评估和排序业务机会，输出决策级洞察报告。

**给谁用：** 需要做方向选择的团队或组织——创业公司选赛道、企业探索新业务线、投资人评估赛道机会。

**解决什么问题：** 凭直觉选方向 / 被现有业务框住 / 知道市场大但不确定能不能做 / 机会太多无法系统比较。

## 核心设计

**市场优先** — 强制前四看纯客观，不被自身业务框住。

**双维解耦** — 市场吸引力与组织适配度独立计算、独立呈现，互不干扰：

- **市场吸引力（100分）**：市场规模 30% · 盈利潜力 25% · 竞争空白 20% · 时机窗口 15% · 风险可控 10%。只看市场，不引入任何组织信息。
- **组织适配度（100分）**：技术匹配 30% · 资源匹配 25% · 渠道匹配 25% · 战略协同 20%。只看组织，不参考市场规模。

两个分数独立计算、独立呈现，不合并为单一总分；每个维度需给出50–100字评分依据。

**四象限定位** — 双维交叉分类（适配度≥50 / 吸引力≥60），仅对明星区做落地验证：

| 象限 | 含义 | 处理方式 |
| --- | --- | --- |
| 明星区 | 市场高 · 组织高 | 优先推进 |
| 幼童区 | 市场高 · 组织低 | 观察待培育 |
| 金牛区 | 市场低 · 组织高 | 存量优化 |
| 瘦狗区 | 市场低 · 组织低 | 暂不投入 |

**落地验证** — 明星区机会过四道筛子，拒绝“看着好但做不了”：短期收入（能否3个月内产生第一笔付费收入？）、执行带宽（组织当前带宽能否支撑？）、资源可承受（启动成本是否在可承受范围？）、渠道可触达（目标客户是否现有渠道可触达？）。

验证结果：全通过 → 优先推进；条件通过 → 标注前置条件；不通过 → 降级或放弃。

## 从哪里开始

只想回答一个具体问题，就用一个独立技能；想从已有资料继续往下做，就选对应流程；想从头走完“五看”，就选完整洞察。每个入口只交付它负责的阶段，不会默认把单项调研扩展成11份报告。

无论选哪个入口，首次使用都先完成**3轮15问**：组织构成6题、产品与技术4题、资源与渠道5题，用来确定调研范围和资源约束。已有答案会先核对，再复用或补问缺项。

### 独立技能（4）

- `strategy-trends` — **看趋势**：行业、技术、政策、市场规模和价值迁移；交付行业趋势简报。
- `strategy-customers` — **看客户**：客户分层、痛点、付费意愿、触达渠道和决策链；交付客户市场简报。
- `strategy-competitors` — **看对手**：头部玩家、同阶段竞品、替代方案、定价和技术路线；交付竞争格局简报。
- `strategy-capabilities` — **看自己**：团队能力、资源、产品与技术资产；交付内部能力盘点。

### 组合流程（4）

- `/four-views` — **四看调研**：摸清行业、客户、对手和自身条件。交付**调研方案、行业趋势简报、客户市场简报、竞争格局简报、内部能力盘点**，共5份。
- `/find-opportunities` — **寻找机会**：基于四看寻找可能的业务方向。交付**机会扫描清单、8维深描文档**，共2份；到此停止，不评分。
- `/compare-opportunities` — **比较机会**：比较用户指定或已筛出的方向。交付**双维评分表、战略矩阵可视化、落地验证报告**，共3份；只对明星区做落地验证。
- `/strategy-insight` — **完整洞察**：从调研启动走完“五看”。交付以上5＋2＋3份过程成果，再加**战略机会洞察报告**，共11份。

这里列的是每条流程的**目标交付物**。如果缺少前置调研，流程会先补做并交付缺少的材料；已有且仍适用的材料直接复用。单独运行“寻找机会”或“比较机会”，不会自动生成最终的战略机会洞察报告。

例如，直接拿三个方向来“比较机会”：若没有四看资料，就先补齐四看；若这三个方向还没有8维深描，就逐个补做。然后交付评分表、矩阵和落地验证报告。不会为了比较这三个方向，虚构一份30–50项的全市场机会扫描清单。

在 Claude 插件中，命令会带插件名前缀，例如 `/strategic-opportunity-insight:four-views`。在 Codex 中，使用 `$strategy-insight` 并说明想运行哪条流程。安装时看到的第五个技能 `strategy-insight`，就是四条组合流程的共同入口。

### 使用示例

单独调研：

> 使用 `$strategy-customers`，研究中小餐饮企业在数字化经营上的主要痛点和付费意愿。

> 使用 `$strategy-competitors`，梳理中国宠物医疗软件市场的主要玩家和替代方案。

运行组合流程（Codex）：

> 使用 `$strategy-insight`，寻找中小餐饮企业数字化服务的业务机会。

> 使用 `$strategy-insight`，比较我提供的三个方向，找出哪些值得优先验证。

运行组合流程（Claude 插件）：

> `/strategic-opportunity-insight:four-views 中国宠物医疗行业`

> `/strategic-opportunity-insight:strategy-insight 中国宠物医疗行业`

## 安装

两种方式，选一种。**Claude Code 插件**安装整套技能和斜杠命令，由插件管理；**skills.sh** 让你选择需要的技能，安装到 Codex、Claude Code 或其他 Agent。若你在 Claude Code 使用插件，就不用再通过 skills.sh 安装同一套技能，以免重复。

### Claude Code：安装完整插件

从本 GitHub 仓库安装，需要先添加仓库来源，再安装插件：

```bash
claude plugin marketplace add tea-del/strategic-opportunity-insight
claude plugin install strategic-opportunity-insight@strategic-opportunity-insight-marketplace
```

安装后，直接使用四个独立技能，或输入 `/strategic-opportunity-insight:four-views` 等命令启动组合流程。在 Claude Cowork 中，可通过插件界面添加仓库 `tea-del/strategic-opportunity-insight` 并安装。

### Codex 和其他 Agent：选择需要的技能

```bash
npx skills@latest add tea-del/strategic-opportunity-insight
```

安装器会让你选择技能、目标 Agent，以及安装到当前项目还是全局。只想做其中一看，就选对应技能；想用组合流程，选 `strategy-insight`；想用全部功能，就选5个技能。

skills.sh 安装的是技能文件，不会添加 Claude 插件中的斜杠命令。在 Codex 中要运行组合流程，调用 `$strategy-insight`，再说明“四看调研”“寻找机会”“比较机会”或“完整洞察”。

以上安装命令面向本地 Agent，不会直接安装到普通 ChatGPT 网页对话。

## 使用边界

本工具只覆盖“五看”（战略洞察），不替团队完成“三定”（战略决策）。调研结论应标注来源和时间，不把估算写成事实。项目采用 [Apache-2.0 许可证](LICENSE)。
