## 📌 这是什么

战略机会洞察是面向任何行业的战略机会调研工具，演变自华为"五看"战略洞察框架，融合波士顿矩阵双维定位思想，帮助团队从市场全景出发，系统识别、评估和排序业务机会，输出决策级洞察报告。

**🎯 给谁用：** 需要做方向选择的团队或组织——创业公司选赛道、企业探索新业务线、投资人评估赛道机会。

**💡 解决什么问题：** 凭直觉选方向 / 被现有业务框住 / 知道市场大但不确定能不能做 / 机会太多无法系统比较。

## 🧩 核心设计

**市场优先** — 强制前四看纯客观，不被自身业务框住

**双维解耦** — 市场吸引力与组织适配度独立计算、独立呈现，互不干扰：
- 📊 **市场吸引力（100分）**：市场规模 30% · 盈利潜力 25% · 竞争空白 20% · 时机窗口 15% · 风险可控 10%
  - 只看市场，不引入任何组织信息
- 👥 **组织适配度（100分）**：技术匹配 30% · 资源匹配 25% · 渠道匹配 25% · 战略协同 20%
  - 只看组织，不参考市场规模

> ⚠️ 两个分数独立计算、独立呈现，不合并为单一总分 · 每个维度需给出50-100字评分依据

**四象限定位** — 双维交叉分类（适配度≥50 / 吸引力≥60），仅对明星区做落地验证：

| ⭐ 明星区（双高） | 🌙 幼童区（市场高·组织低） |
|:---:|:---:|
| 优先推进 | 观察待培育 |
| **🐄 金牛区（组织高·市场低）** | **🐕 瘦狗区（双低）** |
| 存量优化 | 暂不投入 |

**落地验证** — 明星区机会过四道筛子，拒绝"看着好但做不了"：

💰 短期收入（能否3个月内产生第一笔付费收入？） → ⚙️ 执行带宽（组织当前带宽能否支撑？） → 💵 资源可承受（启动成本是否在可承受范围？） → 📡 渠道可触达（目标客户是否现有渠道可触达？）

验证结果：✅ 全通过 → 优先推进 ｜ ⚠️ 条件通过 → 标注前置条件 ｜ ❌ 不通过 → 降级或放弃

## ⚡ 调研流程

五阶段递进式调研——前四看强制纯客观，所有数据标注来源链接。

| 阶段 | 名称 | 方法论 | 维度 | 产出 |
|:----:|------|--------|:----:|------|
| Phase 0 | 调研启动 | 结构化 Q&A | 3轮15题 | 组织信息 + 调研方案 |
| 第一看 | 看趋势 | PEST 分析 | 7维 | 行业趋势简报 |
| 第二看 | 看客户市场 | 市场细分 | 5维 | 客户市场简报 |
| 第三看 | 看对手 | 波特五力 | 6维 | 竞争格局简报 |
| 第四看 | 看自己 | VRIO 框架 | 4维 | 内部能力盘点 |
| 第五看 | 看机会 | 波士顿/GE 矩阵 | 5个Phase | 机会扫描→深描→评分→矩阵→验证→汇总 |

**预计耗时：** 2-3天（含调研+评估全流程）

## 🚀 快速开始

### 获取方式

**方式1：URL引用（推荐，最简洁）**

直接告诉你的 Agent：

> 请使用战略调研框架：https://github.com/tea-del/strategic-opportunity-insight
> 
> 读取 `SKILL.md` 作为执行指令，`scripts/strategy_matrix.html` 用于生成可视化矩阵

Agent 会自动读取仓库内容并开始引导。

**方式2：复制粘贴（最稳定）**

1. 复制 [`SKILL.md`](./SKILL.md) 的全部内容
2. 粘贴到你的 Agent 的系统提示词（System Prompt / Instructions）中
3. 复制 [`scripts/strategy_matrix.html`](./scripts/strategy_matrix.html) 的内容附上（用于可视化输出）
4. （可选）将 `references/` 下的文件作为补充知识库

### 第一次使用

在你的 Agent 对话中说：

```
开始战略机会调研
```

或

```
帮我调研 [某某行业] 的战略机会
```

Agent 会启动 **Phase 0：调研启动**，进行 3 轮共 15 题结构化 Q&A（约 30 分钟）：

| 轮次 | 内容 | 题目数 |
|------|------|--------|
| 第1轮 | 组织构成（人数、角色、技能、投入时间等） | 6题 |
| 第2轮 | 产品与技术（产品阶段、用户数、技术栈等） | 4题 |
| 第3轮 | 资源与渠道（资金、渠道、协作方式、调研方向） | 5题 |

回答完成后，Agent 自动进入调研流程。

## ⚠️ 使用须知

| | |
|----------|----------|
| **你需要做什么** | 回答3轮共15个问题（约30分钟），确定要调研的行业方向 |
| **工具自动完成** | 联网调研 → 机会扫描 → 深描 → 评分 → 矩阵 → 验证 → 输出 |
| **输出格式** | Markdown报告 + HTML可视化大图，共11份交付物 |
| **不需要** | 任何API密钥、付费账号、外部数据订阅 |
| **预计耗时** | 2-3天（含调研+评估全流程） |
| **Agent要求** | 需支持联网搜索和网页阅读 |

**适用场景：**
- "调研某某行业机会"
- "评估某某方向值不值得做"
- "团队下一步做什么方向"
- "市场进入决策"
- "竞品分析+机会识别"

**边界说明：**
- ⚠️ 本工具只覆盖"五看"（战略洞察），不包含"三定"（战略决策）
- 五看产出的是"看到什么机会"，三定（定控制点/定目标/定策略）由团队自行决策
