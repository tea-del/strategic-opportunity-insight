**面向任何行业的战略机会调研工具**

## 📌 这是什么

一个纯自然语言指令文档，让任意支持联网搜索的 AI Agent 变成你的战略调研分析师。不需要写代码、不需要付费 API，把指令传给 Agent，回答 15 个问题，剩下的全自动。

> ⚠️ **只做洞察，不做决策。** 五看产出"看到什么机会"，三定（定控制点/定目标/定策略）由团队自行决策。

## 🧩 核心设计

**双维解耦** — 市场吸引力与组织适配度独立计算、独立呈现，不混合为单一分数：
- 📊 **市场吸引力（100分）**：市场规模 30% · 盈利潜力 25% · 竞争空白 20% · 时机窗口 15% · 风险可控 10%
- 👥 **组织适配度（100分）**：技术匹配 30% · 资源匹配 25% · 渠道匹配 25% · 战略协同 20%

**四象限定位** — 双维交叉分类，仅对明星区做落地验证：

| ⭐ 明星区（双高） | 🌙 幼童区（市场高·组织低） |
|:---:|:---:|
| 优先推进 | 观察待培育 |
| **🐄 金牛区（组织高·市场低）** | **🐕 瘦狗区（双低）** |
| 存量优化 | 暂不投入 |

**落地验证** — 明星区机会过四道筛子：💰 短期收入 → ⚙️ 执行带宽 → 💵 资源可承受 → 📡 渠道可触达

## 🚀 使用方式

1. 📥 前往 [Releases](../../releases) 下载 `strategy-insight.skill` 文件
2. 📤 在 Coze 平台上传该技能包
3. 💬 Agent 启动 Phase 0，开始 3 轮共 15 题结构化 Q&A（约 30 分钟）
4. 🤖 Agent 自动完成联网调研 → 机会扫描 → 深描 → 评分 → 矩阵 → 验证
5. 📦 输出 11 份交付物 + 1 份战略机会洞察报告

> **要求：** AI Agent 需支持联网搜索和网页阅读，建议使用能力较强的大模型。
