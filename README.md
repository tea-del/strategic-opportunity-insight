# 战略机会洞察 Skill

基于华为"五看"框架的战略机会调研技能包，融合波士顿矩阵双维定位思想，帮助团队系统识别和评估业务机会。

## 功能特点

- **五阶段递进式调研**：看趋势 → 看客户 → 看对手 → 看自己 → 看机会
- **双维矩阵评估**：市场吸引力 × 组织适配度，独立计算、独立呈现
- **落地验证**：短期收入、执行带宽、资源可承受、渠道可触达四维度验证
- **战略矩阵可视化**：ECharts 四象限散点图，直观展示机会分布
- **数据驱动**：通过联网搜索获取数据，不依赖付费 API

## 安装方法

1. 前往 [Releases](https://github.com/tea-del/strategic-opportunity-insight/releases) 页面
2. 下载 `strategy-insight.skill` 文件
3. 在 Coze 平台上传该技能包
4. 在对话中即可调用该技能

## 使用场景

- 行业研究与市场机会扫描
- 创业方向选择与评估
- 市场进入决策支持
- 业务机会优先级排序
- 资源配置决策参考

## 执行流程

| 阶段 | 内容 | 说明 |
|------|------|------|
| Phase 0 | 调研启动 | 结构化 Q&A 收集组织信息 |
| 第一看 | 看趋势 | PEST 分析，7 个维度 |
| 第二看 | 看客户 | 市场细分，5 个维度 |
| 第三看 | 看对手 | 波特五力，6 个维度 |
| 第四看 | 看自己 | VRIO 框架，4 个维度 |
| 第五看 | 看机会 | 五步法：扫描→深描→评估→验证→输出 |

## 技术说明

- **数据来源**：联网搜索 + LLM 分析，无需外部 API
- **可视化**：ECharts 散点图，深色主题，四色象限标注
- **并行执行**：支持多子任务并行调研，提升效率
